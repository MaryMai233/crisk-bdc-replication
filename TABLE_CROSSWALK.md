# Table crosswalk to Jung, Engle, and Berner (2025)

Version 4.3 deliberately keeps only the displays needed for the paper's core argument. Detailed robustness tables remain in each module's `Results/` directory but are no longer repeated in the paper.

**Climate-factor scope:** the original paper constructs four climate transition factors (Stranded Asset, Emission, BMG, and CEP). This archive currently replicates the **Stranded Asset factor** only. The top-five and cumulative-75% KOL baskets are two continuation rules for that same factor.

# Data availability

CRSP and Compustat inputs are proprietary and are intentionally excluded from this public repository. Users with WRDS access should obtain daily CRSP security data, Compustat North America quarterly data, and the CRSP/Compustat link table, then place the files in the documented module `Data/Raw/` directories.

SEC filing inputs and public market-series inputs are described by the download and extraction programs in each module. The private replication archive supplied with the paper contains the licensed raw and processed files for authorized use.
